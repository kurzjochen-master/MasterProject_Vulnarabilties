\# Projekt



Masterarbeit



Titel:

Empirische Analyse der Aussagekraft CVSS-basierter Schwachstellenbewertung und Entwicklung eines adaptiven Priorisierungsmodells (AVPM) für Hochschulen



\# Technologien



\- Python 3.13

\- Pandas

\- SQLite

\- Jupyter Notebook

\- SQLAlchemy



\# Datenquellen



\- NVD CVE API 2.0

\- CISA KEV Catalog

\- FIRST EPSS



\# Entwicklungsrichtlinien



\- Rohdaten niemals verändern

\- Rohdaten unter data/raw speichern

\- Transformierte Daten unter data/processed speichern

\- SQLite unter data/database

\- Logging verwenden

\- Type Hints verwenden

\- Kommentare auf Englisch

\- Code modular halten

\- Keine Monolith-Skripte



\# Ziel



Erstellung eines Analyse-Datensatzes zur Untersuchung von:



\- Entwicklung von CVSS-Scores 2015–2026

\- Zusammenhang CVSS und KEV

\- Zusammenhang CVSS und EPSS

\- Unterschiede zwischen Produktgruppen

\- Entwicklung eines Adaptive Vulnerability Prioritization Model (AVPM)
